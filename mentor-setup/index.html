Kindo Mentor — Setup & Walkthrough Guide

Overview

Kindo Mentor is an AI-powered training and curriculum management app for Atlassian Jira. It uses the Feynman Teaching Method to deliver personalized, mastery-based learning tied to your organization's actual knowledge sources.

Five AI agents work together to manage every aspect of organizational training:

Agent Role Description
KNOT App Configuration Guide Setup help, health checks, discovery
SENSEI Curriculum Management Create programs, define standards, manage lifecycle
MENTOR Personalized Teaching Feynman method, baseline assessment, mastery tracking
COACH Ad-hoc Learning Feynman teaching within policy, on-demand help
VERIFIER Assessment & Certification Independent mastery validation, certification management

Prerequisites

  • Jira Cloud instance with Rovo enabled
  • Site admin permissions (for initial install)
  • At least one Jira project or Confluence space with organizational knowledge content

Step 1 — Install & Get Started

After installing Kindo Mentor from the Atlassian Marketplace:

  1. Navigate to Jira Admin Settings → Manage Apps → Kindo Mentor
  2. The Get Started page shows a 7-item setup checklist

Auto-completed on Install

Three items complete automatically when the app is installed:

  • ✅ Training project created — a dedicated TRAINING project is created in your Jira instance
  • ✅ Learning framework applied — the KinHelm Training Framework is configured
  • ✅ Discovery scan complete — your Atlassian site is scanned for existing knowledge content (Confluence spaces, Jira projects) relevant to training

Requires Your Configuration

Four items require manual setup:

Checklist Item Status
Training team assigned ⚠️ Configuration required
Curriculum sources configured ⚠️ Configuration required
Certification requirements defined ⚠️ Configuration required
Peer apps connected ⚠️ Configuration required

Click “Configure App” to begin setup, or talk to KNOT — your configuration agent — for guided help.

Step 2 — Configure: Training Team

Navigate to Configure → Training Team tab. Add team members who will manage curricula, review training outcomes, and oversee certifications.

For each member, enter:

Field Description
Atlassian Account ID Their Jira account identifier
Display Name How they appear in the app
Role e.g., Training Admin

Click “Add Member” then “Save”. A green confirmation banner confirms the save was successful.

Step 3 — Configure: Curriculum Sources

Navigate to Configure → Curriculum Sources tab. Define where MENTOR pulls organizational knowledge from — Confluence spaces, Jira projects, or uploaded materials.

For each source, enter:

Field Description
Source Type Jira or Confluence
Identifier Project key or space key (e.g., EO for an Employee Onboarding project)
Display Name A readable label for the source
Refresh Frequency How often to check for content updates (e.g., Weekly)

Click “Add Source” then “Save”.

[Screenshot: Curriculum Sources configuration]

Step 4 — Configure: Additional Tabs

The Configure page includes additional tabs for fine-tuning your training environment:

Tab Description
Certification Requirements Define pass thresholds, assessment types, validity periods, and recertification triggers. These can also be created automatically when SENSEI builds a curriculum (see Step 6).
Feynman Method Configure the teaching methodology parameters that MENTOR uses during learning sessions.
Content Change Detection Set sensitivity for detecting when source material changes. Changes trigger retraining alerts automatically.
Ecosystem View connected Kindo peer apps. The app operates in standalone mode if no other Kindo apps are installed. Ecosystem features activate automatically when peers are detected.
Tip

Accept the defaults for all tabs other than Certification Requirements.

Step 5 — Create a Curriculum with SENSEI

SENSEI is your curriculum management agent. To create a training program:

  1. Open Rovo Chat (click “Ask Rovo” in the top navigation bar)
  2. Select SENSEI (Kindo) from your available agents
  3. Tell SENSEI what curriculum to create. Example: “Help me develop a curriculum for employee onboarding using Jira space EO”

SENSEI will ask for details:

Field Description
Program Name The title of the curriculum
Source Content Where the source material lives
Learning Objectives Key outcomes learners should achieve
Recertification Period How often learners should be retrained (default: 365 days)
Description A brief overview of the program

Once you confirm, SENSEI creates:

  • A Jira issue in the TRAINING project (e.g., TRAINING-2) with the full program details
  • A unique Program ID
  • Linked source references to your content
  • Auto-generated learning objectives based on the source material

SENSEI provides next steps: content monitoring, training cycle creation, and baseline assessments for learners.

Step 6 — Define Mastery Standards with SENSEI

After creating a curriculum, ask SENSEI to define the mastery standards. In the same Rovo chat, ask: “Help me define the mastery standards for this”

SENSEI proposes a mastery framework including:

Assessment Thresholds

Pass scores (e.g., 80% for general modules, 100% for compliance), attempt limits before admin review.

Competency Levels

A four-tier progression:

Level Name Description
Level 1 Novice Completed reading, not yet assessed
Level 2 Developing Passed assessments, still needs guidance
Level 3 Proficient Independent operation in internal systems (target mastery)
Level 4 Expert Capable of mentoring others

Evidence of Mastery

Practical tasks tied to Atlassian usage (e.g., completing Jira tasks in the source project, creating Confluence pages).

Review and confirm or customize the standards. SENSEI writes the certification requirements to the TRAINING project and updates your app configuration.

Step 7 — Begin Learning with MENTOR

MENTOR is your personalized teaching agent, built on the Feynman Teaching Method.

  1. Open Rovo Chat and select MENTOR (Kindo)
  2. Ask about your learning profile: “What is my learning profile?”
  3. If no profile exists, MENTOR initiates a baseline assessment to understand how you learn
  4. MENTOR asks about your role and day-to-day work before starting any teaching — it adapts to you, not the other way around

From there, MENTOR teaches from the curriculum content using the Feynman cycle:

  • Explain — presents concepts in plain language
  • Check — probes your understanding with targeted questions
  • Identify — finds gaps in comprehension
  • Gate — does not advance to the next concept until mastery is demonstrated
Tip

Progress is tracked against your baseline — growth-based assessment, not pass/fail.

Step 8 — Verify Setup Progress

Return to the Get Started page to verify your progress. After completing all configuration steps and creating a curriculum with SENSEI, all items should show green.

Item Notes
Certification requirements These can be defined manually in Configure, or they are created automatically when SENSEI builds a curriculum with mastery standards (see Steps 6 and 7).
Peer apps Shows green in standalone mode. If other Kindo apps (Governance, HR, Compliance, Change, Legal) are installed, peer connections are detected automatically.

Key Design Principles

  • All data stays in your Atlassian environment — Forge Storage and Jira issues. No external data storage.
  • Gaps are attributed to the material, not the learner — if understanding isn't there, the teaching adapts.
  • Content changes trigger retraining — when source material is updated, affected learners are automatically flagged for delta retraining.
  • Certification requirements can be created two ways — manually through the Configure page, or automatically when SENSEI creates a curriculum with mastery standards.
  • Standalone by default, ecosystem-ready — works fully as a single app. When other Kindo apps are installed, cross-app features activate automatically.

Troubleshooting

Issue Solution
Get Started buttons don't navigate Verify the app is upgraded to the latest version (forge install --upgrade)
Configure page is blank Check browser console for errors. Ensure the app is deployed and upgraded.
Agent not responding Verify Rovo is enabled on your Jira site. Check that the agent appears in Browse Agents.
Certification requirements not showing Create a curriculum via SENSEI — requirements are generated automatically. Or define manually in Configure → Certification Requirements.
Peer apps not detected Other Kindo apps must be installed on the same Jira site. The app works fully in standalone mode.
